# Hishab Ledger v1.0.0

Offline ledger app for tracking dues and payments.

## Setup
1. Extract the project.
2. In Android Studio, choose **Open** and select the `HishabLedger-v1.0.0` folder.
3. Let Gradle sync, then run on a device or build an APK.

## Identifiers
- Package / applicationId: `com.wafyro.hishabledger`
- `versionName` = `1.0.0`, `versionCode` = `1`
